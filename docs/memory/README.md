# Claude memory export

These are the memory entries Claude Code kept while building this archive on the original machine.
Claude's memory is stored per machine (and per project path), so it does not travel with a git clone.

**On a new machine, either:**

* point Claude at this folder ("read `docs/memory/`") at the start of a session, or
* ask it to re-create the entries in its own memory directory from `CLAUDE.md` + these files.

| File | What it records |
|---|---|
| `mlops-notes-format.md` | how the notes are built: HTML per chapter + executed notebooks for coding chapters, plus build-machine gotchas |
| `mlops-after-course-todo.md` | the habit of appending deferred, account-based steps to `notes/todo_after_course.html` |
| `mlops-chapter-scope.md` | the decision to cover GitHub Actions only (Jenkins/CircleCI are placeholders) and the chapter numbering |
| `MEMORY.md` | the index Claude loads each session |
