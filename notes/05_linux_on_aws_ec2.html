01Two ways to get a Linux terminal 01:25:46

Before using AWS, the instructor shows an alternative. The course itself uses a cloud server, because every later project is deployed to one.

ALTERNATIVE · FREE, LOCAL

WSL: Windows Subsystem for Linux

  • Search "WSL" or "Ubuntu" in the Microsoft Store and install Ubuntu.
  • You get a real Linux (bash) terminal running on your Windows machine.
  • Limitation: the instructor notes that some commands behave differently or don't work there.
  • Nothing to terminate, and no cloud bill.
USED IN THE COURSE

AWS EC2 (cloud VM)

  • This is what a production environment actually looks like.
  • Every Linux command works.
  • You need an AWS account, and it costs money while it's running (the free tier covers small instances).
Beyond the video · other options

macOS: the Terminal app is Unix-like (zsh) and shares most commands, but apt doesn't exist there (Homebrew fills that role). Docker: docker run -it ubuntu:24.04 bash gives you a disposable Ubuntu shell on any OS. Both are fine for practising commands, but EC2 is the real target.

02What EC2 is 01:27:52

EC2 (Elastic Compute Cloud) is AWS's virtual machine service. You rent a computer in the cloud. Each rented machine is called an instance. As covered in Chapter 04, it's a real computer as far as your code is concerned, with its own CPU, RAM, disk and OS.

When you launch one, AWS offers many operating system images (AMIs, Amazon Machine Images):

03Launching the instance, step by step 01:28:00

  1. Open EC2

    In the AWS console, search for EC2 and click Launch instance.

  2. Name it

    Any name works. The instructor uses Linux desktop.

  3. Pick the OS image (AMI)

    Select Ubuntu, then the latest LTS (Long-Term Support) version, Ubuntu 24.04 LTS. LTS releases get about 5 years of security updates, which is why servers use them.

  4. Pick the instance type

    This decides CPU and RAM. The instructor chooses t2.micro because he's only demonstrating commands, not deploying anything, and it's free-tier eligible. See the next section.

  5. Create a key pair

    Click Create new key pair and give it a name (the instructor uses Linux test). A key file downloads. You need it to connect with SSH clients such as PuTTY or MobaXterm. The instructor connects through the browser instead.

  6. Network settings

    Tick Allow HTTP traffic and Allow HTTPS traffic from the internet, so a web app on this machine can be reached later.

  7. Storage

    Keep the default 8 GB disk.

  8. Launch

    Leave everything else at the defaults and click Launch instance. Wait until the state shows Running.

  9. Connect

    Open the instance, click Connect → EC2 Instance Connect → Connect. A black bash terminal opens in the browser. This is your production environment.

Check before relying on this · free credit

The instructor says new accounts get "$300 credit". AWS's free-tier terms have changed over time, and $300 is actually Google Cloud's trial amount. Check the current AWS Free Tier page before launching anything, and set a billing alarm / budget in the Billing console on day one.

1 GiB is tight once you install pandas, scikit-learn and Docker. pip install can run out of memory on t2.micro. For the end-to-end deployment later in the course, plan on t2.medium or larger. 05Key pairs and the security group 01:29:58

🔑 Key pair

AWS keeps the public key on the instance, and you download the private key (.pem for OpenSSH, .ppk for PuTTY). Only someone holding that file can log in over SSH. You can download it once, so store it safely and never commit it to Git.

🛡 HTTP / HTTPS checkboxes

These open ports 80 and 443 so a web app on the instance can be reached from a browser. Later you'll also open your app's own port (for example 8000 or 8080) as an inbound rule.

08Terminating: don't leave it running 01:53:08

At the end of the commands session, the instructor deletes the machine. A running instance keeps charging you.

  1. Close the terminal tab.
  2. Go to EC2 → Instances (sign in again if the session expired).
  3. Select the instance → Instance state → Terminate → confirm.
  4. After a short while the state shows Terminated, meaning the instance has been deleted.

Do this every time you create a practice instance. With WSL there's nothing to clean up.

09Try it yourself

Practice checklist
  1. Create a budget alert (Billing → Budgets) for a small amount such as $5.
  2. Launch Ubuntu 24.04 LTS on a free-tier type, create a key pair, and tick HTTP/HTTPS.
  3. Connect with EC2 Instance Connect, then again with ssh -i from your laptop.
  4. Run whoami, pwd, hostname, free -h and df -h, and match the output to the instance type you chose.
  5. Work through the Chapter 06 commands on this machine.
  6. Terminate the instance and confirm the state says Terminated.

10Interview questions

What is EC2, and what is an AMI?

EC2 is AWS's virtual machine service; each VM is an instance. An AMI (Amazon Machine Image) is the template the instance boots from: the OS (such as Ubuntu 24.04) plus any pre-installed software.

How do you choose an instance type for serving a model?

Base it on the model's memory footprint, request volume and whether it needs a GPU. Small scikit-learn APIs run on t-family burstable instances (t2/t3 small or medium). Memory-heavy models need r-family, and deep learning inference or training needs g/p-family GPU instances. Start small, load-test, then scale up or out. Bigger instances cost more per hour.

What's the difference between a key pair and a security group?

A key pair is authentication: it proves who can log in over SSH, using the private key file. A security group is a firewall: it decides which ports and sources can reach the instance at all (for example 22 for SSH, 80/443 for web, 8000 for your API).

Stop vs terminate?

Stop shuts the VM down but keeps its EBS disk, so you pay only for storage and can start it again. Terminate deletes the instance and, by default, its root disk, so there are no further charges and no way to recover it.

Why use an LTS release on servers?

Long-Term Support releases (such as Ubuntu 24.04) get around 5 years of security and maintenance updates, so production machines stay patched without a major OS upgrade every few months.

What is WSL and when would you use it?

Windows Subsystem for Linux runs a Linux distro (such as Ubuntu) inside Windows. It's useful for local development and practising commands without cloud costs, but production still runs on real Linux servers.

11Recap

  • Two options: WSL (local, free, a few commands behave differently) or an AWS EC2 cloud VM (the real production setting).
  • Launch: EC2 → Launch instance → name → Ubuntu 24.04 LTS → t2.micro → key pair → allow HTTP/HTTPS → 8 GB → Launch.
  • Instance type sets RAM and CPU: small 2 GB, medium 4 GB, large 8 GB. Bigger costs more.
  • Connect with EC2 Instance Connect to get a browser bash terminal. The prompt shows the user and the machine's IP-based hostname.
  • When you're done: Instance state → Terminate, or it keeps charging you.
