05Account, free credit and regions 03:17:00

Sign up, fill in your details and add a card. AWS makes a small verification charge.

Check before relying on this · free credit (again)

The instructor repeats that you get "$300 free credit". As noted in Chapter 05, $300 is Google Cloud's trial amount. AWS's free-tier offer is different and has changed over time, so check the current AWS Free Tier page and set a budget alert first.

Regions

Always check which region you're working in, shown at the top right of the console. The instructor uses us-east-1 (N. Virginia). AWS has servers in many locations, such as Mumbai, Osaka and N. Virginia. Choose the region nearest to you for the fastest communication:

Beyond the video · three region rules that cost people money
  • Resources are regional. An instance launched in Mumbai is invisible while the console is set to N. Virginia, but it's still running and still billing.
  • Prices differ by region, and not every service or instance type exists everywhere.
  • Keep related resources in one region (EC2 + S3 + ECR) to avoid cross-region data-transfer charges and latency. Some data must stay in-country for legal reasons (data residency).

07ECR vs Docker Hub 03:20:10

When you containerise an app with Docker, the resulting image has to be stored somewhere a server can pull it from. The instructor shows Docker Hub, which has ready-made images such as PyTorch that you can docker pull and run with Docker Desktop, and compares it with ECR.

🐳 Docker Hub

The public image library: official images for Python, PyTorch, Ubuntu… The instructor describes it as public.

📦 AWS ECR

A private registry for your own project images, inside your AWS account. EC2, ECS, EKS and SageMaker can pull from it directly using IAM permissions.

Clarification

Docker Hub also offers private repositories (limited on the free plan). The practical reasons to choose ECR for AWS deployments are IAM-based access, staying in the same region and network as your servers, and integration with AWS deployment services.

Docker itself is covered from 4:05:17.

10IAM: why not just use the root account? 03:25:26

Learners often ask why IAM is needed. To access AWS services from code, you use an access key and a secret key. If those keys belong to the root account or an administrator, your application can reach every service, and you could end up with a huge bill.

So for every project, create a specific IAM user and attach only the permissions (a policy) it needs, instead of using root.

Beyond the video · IAM essentials for interviews and real deployments
ConceptMeaning
UserA person or app with long-term credentials (console password and/or access keys)
GroupA set of users that share policies (e.g. "data-scientists")
RoleTemporary credentials that a service assumes, e.g. an EC2 instance role, so no keys are stored on the server
PolicyA JSON document: Effect + Action + Resource. Anything not allowed is denied by default.
 
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["s3:ListBucket", "s3:GetObject", "s3:PutObject"],
    "Resource": ["arn:aws:s3:::team-data-bucket", "arn:aws:s3:::team-data-bucket/*"]
  }]
}
  • Turn on MFA for the root account, then stop using it day to day.
  • Never commit keys to Git. Use aws configure locally, GitHub Actions secrets in CI, and roles on EC2 and SageMaker.
  • If a key leaks, deactivate it immediately and create a new one.
Mentor's note from the video

The instructor can show the path and the resources, but becoming a good developer takes your own exploration. Open the services, read the docs and practise.

11Interview questions

Why do ML projects need the cloud at all?

For on-demand compute (CPUs and GPUs for training), durable shared storage for data and artifacts, managed services (registries, pipelines, ML platforms), and above all a place to serve the model 24×7 to real users with scaling, monitoring and security, without buying and running your own hardware.

Map these AWS services to their GCP equivalents: EC2, S3, ECR, SageMaker.

EC2 → Compute Engine · S3 → Cloud Storage · ECR → Artifact Registry · SageMaker → Vertex AI. (Azure: Virtual Machines, Blob Storage, ACR, Azure ML.)

What's the difference between a region and an availability zone?

A region is a geographic area (e.g. ap-south-1, Mumbai). It contains several availability zones: isolated data centres with independent power and networking. Spread instances across AZs for high availability, and choose the region for latency, cost, service availability and data-residency rules.

You need to deploy a model API on AWS. What are your options?

(1) EC2 running Docker, the most control. (2) Elastic Beanstalk, a managed platform. (3) ECS or EKS with an image from ECR, for container orchestration and scaling. (4) SageMaker endpoints, managed model hosting with autoscaling. (5) Lambda, for small, light, infrequent models. The choice depends on traffic, latency, team skills and cost.

Explain IAM users, roles and policies. Why not use root keys?

Users hold long-term credentials. Roles give temporary credentials to services or federated users. Policies are JSON allow/deny rules attached to either. Root keys have unlimited power, so a leak or a bug can delete resources or run up huge bills. Follow least privilege and prefer roles, so no keys sit on servers.

S3 vs EBS vs EFS?

S3 is object storage over HTTP (datasets, models, artifacts), effectively unlimited and cheap. EBS is a block disk attached to one EC2 instance (the OS and local files). EFS is a shared network file system that several instances can mount.

How do you keep cloud costs under control while learning?

Set budgets and billing alerts, use free-tier or small instance types, stop or terminate instances when you're done, check all regions for forgotten resources, delete unused EBS volumes, snapshots and ECR images, and set lifecycle rules on S3.

12Recap

  • Each pipeline component uses tools (databases, Evidently, DVC, MLflow, Jenkins/CircleCI/GitHub Actions), and deployment runs on a cloud.
  • Providers: AWS, GCP, Azure, Alibaba. The instructor prefers AWS and GCP. The services are the same with different names, so master one cloud.
  • AWS for this course: EC2, S3, ECR, IAM, SageMaker, CodePipeline, Elastic Beanstalk. GCP's MLOps platform is Vertex AI.
  • Always check the region (the video uses us-east-1) and pick the nearest one. Verify the free-credit claim and set budget alerts.
  • ECR is a private Docker image registry, similar to Docker Hub. SageMaker is paid, since production is never free.
  • IAM: never use root or admin keys in apps. Create users with specific policies (least privilege).
